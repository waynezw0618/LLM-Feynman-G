## 0. 实验设计（对应用户三项指令）

| 要素 | 实现 | 载体 |
|---|---|---|
| GS 修正 W* = W̄ + ε·Ω 进入候选池 | 20 候选张量基中 T5v→T5g（T5 = WS²−S²W，vw 支撑基；GS 修正把系统旋转显式注入其构造） | `rc_pope_gsbuild.py` / `rc_pope_gsonly.py` |

## 2. 因子归因（本实验核心结论）

| 效应 | rho_a mean | tau_e mean | V2 vw 中心峰 | V1 近壁 vv worst |
|---|---|---|---|---|
| 基线 wy | 1.195 | 0.160 | 2/5 | 19.8 |
| **+ GS 换基**（gsonly−wy） | +0.009 ✅ | +0.011（+7%，温和） | **2/5 → 5/5** ✅ | 19.8→40.9（2×，⚠️） |
| **+ ret/roloc**（wy_rt−wy） | −0.031 ❌ | +0.027（+17%） | 无改善 | 19.8→72.4（3.7×）❌ |
| 组合（gsrt） | +0.018 | **+0.118（+74%，超加性）** ❌ | 4/5 | 413 ❌❌ |

三条结论：

1. **V2 中心峰的改善完全来自 GS 换基**：gsonly（5/5）> gsrt（4/5）> 基线（2/5）。gsonly 中心均值 0.053–0.069 vs DNS 0.037–0.059，且峰值位置正确（|y/h|≤0.2，gsrt 的幂律公式峰值跑到了壁面 y/h=±1）。物理上对症：T5 = WS²−S²W 是 vw 支撑基，GS 修正 W* = W̄+ε·Ω 把系统旋转显式注入其构造——**这是三次特征/基底实验中第一个兑现物理预期的干预**。
2. **ret/roloc 自由特征第三次净负验证**（pope3、wy_rt、gsrt 同构结论）：GP 把它们当幂律回归量（T4v best = 纯 ret 幂律），8 个量级的动态范围在 valid_fit 剔除的近壁外推点发散（gsrt uv 全valid 211 vs fit 区 0.22），tau_e 爆炸 0.277。特征空间扩大不稳健的结论现在有 3 次独立证据。
3. **组合的 tau_e 恶化是超加性的**（+74% ≫ +7%+17%）：GS 换基改变了 a_m 目标的空间结构，反而给了 ret/roloc 幂律更多过拟合自由度。两个"各自温和"的干预组合起来不是相加而是相乘地坏。

## 3. 验收明细

### gsrt（组合臂，近壁外推爆炸的完整证据）

- V1 fit 覆盖区 worst：uu 47.4 / vv 413 / ww 83.2 / vw 60.7 ❌❌
- V1 全 valid：uv 211、vw 325（幂律近壁外推发散）
- V2 中心峰 4/5 ✅ 但峰值位置错误（y/h=±1.00，壁面伪峰 0.16–0.42）
- 5 目标 stress loss：T1 0.104 / T2v 0.052 / T3v 0.917 / T4v 0.906 / T5g 0.468

### gsonly（GS 换基单独，本实验最优臂）

- V2 中心峰 **5/5 ✅**（0.053/0.067/0.069/0.053/0.057 vs DNS 0.037/0.045/0.059/0.054/0.034）
- V1 fit 区 worst：uu 12.8 / vv 40.9 / ww 16.2 / uv **0.202（vs 基线 0.385，改善）** / vw 6.5
- V3 壁面特征占用：T1 best 含 log(yw)（100% top-8），T5g 50%
- T5g best = `C1·(zeta2v^C3 · zeta2e^C2)` 纯不变量幂律——不依赖危险特征
- V4 max|a|@fit = 187 ✅

## 4. 采纳决定与下一步

| 项 | 决定 |
|---|---|
| **GS 换基 T5v→T5g（经 p90 段2 放松）** | ✅ **采纳**：vw 中心峰 5/5 + 高 Ro rho_a/tau_r/tau_e 全面改善，代价（低 Ro 近壁 vv 2×）可接受。gsonly 取代 wy 成为 vw 专项新基线 |
| ret/roloc 自由特征 | ❌ **不采纳**（第三次同构证据）。若要用必须走结构先验 pin：a_m = g(不变量)·φ(ret) 乘性阻尼形式，DSL 层约束，不允许 GP 自由组合 |
| 后续 vw 攻坚 | 从 gsonly 出发：固定 {T1,T2v,T3v,T4v,T5g}，专攻 T5g 的 a_5g 表达式（当前纯幂律 loss 0.468 还有余量） |
| 偏相关方法论 | §5.2 口径已落地（`rc_pope_metrics52.py`），后续每个新 arm 直接进四臂对比框架 |

## 5. 局限声明（诚实口径）

- rho_a 为 on-design a priori 对齐（DNS 平均场上），非论文的 RANS a posteriori 回代——上界口径，实际 RANS 回代会额外衰减
- 偏相关 20 点样本、arm 非独立，r 的显著性只做方向参考
- gsonly 与 gsrt 的 GP 搜索为单 seed（seed 由 target 名哈希决定，两臂 T5g 同 seed 可比；与基线 T5v 不同 seed，单因子对照依赖"同预算多次改善方向一致"的稳健性）
- p90 换基代价在高 Ro 工况（p90_cond 442/736）由 coverage 守门保证训练集完整，但 a_m 目标在高 Ro 近壁的信噪比本质上更差
- ε 来自耗散预算重建（rc_asm_prep.py:69–77），ret/roloc 继承其不确定性
