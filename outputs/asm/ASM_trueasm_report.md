# 真 ASM (Algebraic Stress Model) 符号回归对比报告

**任务**: Weatheritt & Sandberg (2016 JCP 325:22-37) eq.(17)-(20) 结构的旋转槽道流代数应力模型 —
单一闭式公式 `b_ij = f(T1..T10, eta2, zeta2, s3, so2, s2o2, ret, roloc)`
对全部 6 分量 × 5 工况 (Ro_τ=7.5..150, Re_τ=180) 通用, 只允许全局常数 C#.

**两方法严格隔离**: PySR = 纯符号回归 (无 LLM / 无物理提示 / 无 LGF 策略);
LGF = MiniMax-M2.7 + 物理上下文 (张量基/不变量/Re_t/Ro_loc 含义注入 G_INIT 与 M_GUIDE),
mg 臂 M_GUIDE 全程开启, go 臂仅 G_INIT. 真 ASM 硬约束: K# 逐工况常数一律 K→C 改写.

**评估**: loss_asm = mean_c(MSE_c/var_c) (行 = 工况×壁面位置×分量);
ρ_a,case = W&S eq.22 逐点张量余弦对 valid 点平均 (全 3×3 Frobenius);
作弊检测 = max|pred| 越界占比 (阈值 20×max|b_ref|, V3-c 同款).

- **cc10 (全局) < cc10_pc (逐工况)**: 常数版 Pope TBFCM 的工况泛化代价;
  rot_factor 越大差越大 (v:0.70→e:0.84), 旋转使最优常数逐工况漂移 —
  这正是 roloc 特征需要捕捉的跨工况差异.
- s3/so2 结构性恒零 (二维平均流); v 变体 zeta2 ≡ eta2 (‖W̄‖²=‖S‖² 恒等).

## 4. 各方法最优公式

### 变体 v

**PySR 纯SR** (复杂度 30, loss_asm=0.4189, ρ_a=0.5381):

```
T8*0.2637855*s2o2*(exp(-4.846445/eta2) + exp(-4.846445*eta2)*exp(eta2/eta2)*s2o2*0.2637855/s2o2)/(s2o2*s2o2)
```
基张量: T8; 标量: eta2, s2o2

**LGF-mg (M_GUIDE)** (复杂度 {'nodes': 12, 'edges': 11, 'params': 3, 'depth': 5}, loss_asm=0.5571, ρ_a=0.5674):

```
(C3 * (1)) * (T7) + C2 * (T2) + C1 * (1) + T2
```
基张量: T2, T7; 标量: (无)

**LGF-go (ginit-only)** (复杂度 {'nodes': 16, 'edges': 15, 'params': 5, 'depth': 6}, loss_asm=0.5121, ρ_a=0.7464):

```
C5 * (T4) + C4 * (T2) + C3 * (T1) + C2 * (T3) + (C1 * (T2)) * (T3)
```
基张量: T1, T2, T3, T4; 标量: (无)

### 变体 g

**PySR 纯SR** (复杂度 29, loss_asm=0.3736, ρ_a=0.6058):

```
(eta2*0.7407941*T4/(s2o2*(2.0976007 - (s3 + 3.3073611))*(exp(s2o2) + exp(s3) - 1*3.3073611)) - T8/s2o2 + s3)*(-0.33395973)
```
基张量: T4, T8; 标量: eta2, s3, s2o2

**LGF-mg (M_GUIDE)** (复杂度 {'nodes': 11, 'edges': 10, 'params': 4, 'depth': 6}, loss_asm=0.6082, ρ_a=0.4784):

```
(C3 * (tanh(C4 * (eta2)))) * (T2) + C1 * (tanh(C2 * (T2)))
```
基张量: T2; 标量: eta2

**LGF-go (ginit-only)** (复杂度 {'nodes': 12, 'edges': 11, 'params': 3, 'depth': 6}, loss_asm=0.3797, ρ_a=0.7249):

```
C3 * (tanh(T1)) + C1 * ((C2 * (T2)) * (inv(eta2 + zeta2)))
```
基张量: T1, T2; 标量: eta2, zeta2

### 变体 e

**PySR 纯SR** (复杂度 28, loss_asm=0.4666, ρ_a=0.4806):

```
(0.38392627*T8 - 0.574540977498582*T9*sqrt(121.45341 - s2o2)/(71.3206093926068 - 0.12034881*s2o2))/s2o2
```
基张量: T8, T9; 标量: s2o2

**LGF-mg (M_GUIDE)** (复杂度 {'nodes': 13, 'edges': 12, 'params': 4, 'depth': 6}, loss_asm=0.5584, ρ_a=0.1602):

```
(C4 * (T8)) / ((C3 * (T7)) / (T7 + C2 * (1)) + C1 * (s2o2))
```
基张量: T7, T8; 标量: s2o2

**LGF-go (ginit-only)** (复杂度 {'nodes': 8, 'edges': 7, 'params': 2, 'depth': 5}, loss_asm=0.5366, ρ_a=0.3798):

```
(C2 * (T2)) * (inv(C1 * (T2) + zeta2))
```
基张量: T2; 标量: zeta2

### 6.2 结构性备注

- s3/so2 恒零: 公式中把它们当常数发生器 (如 `s3 + 3.31` ≡ 常数) 在本流族合法,
  但迁移到三维平均流 (s3≠0) 时语义改变 — 部署前需人工审查.
- v 变体 zeta2 ≡ eta2: 两特征可互换, SR 选其一属正常.
- ret/roloc 进入系数函数是 Re_t/Ro_local 修正生效的直接证据.

## 7. 方法学声明与局限

- **复杂度口径不同**: PySR 复杂度=节点数 (maxsize=30); LGF=边数 (max_edges=16) +
  常数≤6. 两者非严格同预算, 报告按各自帕累托最优呈现.
- PySR 常数无上限 (BFGS 全局拟合); LGF 常数≤6 且 L-BFGS 多启动.
- 单 seed 单次运行 (PySR random_state=0, LGF crc32 seed); 无跨 seed 方差估计.
- 评估在训练数据本身 (无 hold-out): 与 W&S 的 DNS 代数拟合设定一致,
  但不代表跨流型泛化.
- LGF 时间预算 800s/臂 vs PySR 50 迭代 (~40s): 计算量不对等,
  PySR (Julia 多线程) 单位算力远高于 LGF (Python 逐图拟合).
