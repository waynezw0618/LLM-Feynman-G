## 1. 口径定义（本报告所有结果遵循）

目标：将 b23 严格写成张量基形式

```
b23 = Σ_{m∈{1,5,6,10}} a_m(Θ) · T̃⁽ᵐ⁾₂₃
```

- `T̃⁽ᵐ⁾₂₃`：T⁽ᵐ⁾ 的 23 分量按**逐工况 RMS 归一**（消除跨工况 3–4 个量级的动态范围病态）；
- `a_m(Θ)`：待发现的系数函数，Θ = {eta2, zeta2, s2o2, ret, roloc, yw}（Pope 不变量 + 局部旋转数 + 真壁距）；
- **联合基线（上界参照）**：把 a_m(Θ) 参数化为 12 基 × 4 通道 = 48 个全局常数的线性组合，加权最小二乘直接解出（结构化联合拟合）。这是"系数形式表达力"的上界：**g 0.0034 / e 0.0037 / m 0.0001**（系数幅值 O(1)，良态）；
- **SR 阶段**：把联合解的系数 a_m(Θ) 拆成 4 个逐通道靶标，用 PySR / LGF 分别做符号回归发现 a_m(Θ) 的显式公式，再重组回 b23 评估。

## 4. 关键发现

### 4.1 等复杂度约束下 LGF 胜 PySR（公平对照）

PySR 全尺寸（maxsize=25）赢了系数口径的 LGF legacy，但其解的复杂度是 LGF 输出的 2–4 倍。**把 PySR 限制到与 LGF 相当的复杂度（maxsize=12）后，PySR 全面退化**（g: 0.357→1.007, e: 0.963→1.233, v: 4.05→2.91），而 LGF 保持复杂度不变——

- g 基：LGF-mg v2 **0.646** / LGF-go v2 0.693 < PySR-ms12 1.007 ✅
- e 基：LGF-mg v2 **0.983** < PySR-ms12 1.233 ✅（与 PySR full 0.963 持平，但参数少 3–4 倍）

解读：符号回归在系数口径上是"病态靶标上的数值拟合"问题，PySR 的暴力搜索在全尺寸下有优势；但**等参数预算下，LLM 物理先验充当了隐式正则**——LGF 的候选表达式直接落在 ASM 闭包的物理族内（饱和/壁面衰减/有理式），无需搜索垃圾空间。

### 4.2 物理提示的价值（知识消融）

| 基 | LGF-go physics (v2) | LGF-go generic (nophys) | 提示效果 |
|---|---|---|---|
| g | 0.693 | 1.271 | **−45%** ✅ |
| e | 2.923 | 1.897 | +54% ⚠️（反而差） |

两个方向的诚实解读：

- **g 基上物理提示价值明确**（−45%）：nophys 的公式退化为 `log(C·yw+C)·log(C·yw+C)` 这类纯数值结构，物理提示把候选锚定在壁面有理式/饱和族上。
- **e 基 go 臂上物理提示反而带偏**：go 臂的知识注入只在 G_INIT（初始化），e 基的靶标与提示先验的相关结构不匹配时，先验成了**锚定偏置**。
- **臂间差异 > 提示差异**：e 基最优是 mg 臂 + physics（0.983）——mg（每代持续引导）比 go（仅初始化）更稳健地消化知识。知识起作用的正确路径是"持续引导 + 恰当先验"，而非"一次性强提示"。

### 4.3 增强配置的收益

v2（pop80/gens30/8参数/180s）相对 legacy：g_mg 0.938→**0.646**（−31%）、g_go 0.826→0.693（−16%）、e_mg 2.566→0.983（−62%）。搜索预算提升 + 参数上限放宽 + 物理提示升级（SSG/EB-RISM 闭包族显式列举）三者的联合效果。

### 4.4 公式形态：LGF 输出全部落在物理族内

**g 基冠军 LGF-mg v2（loss 0.646）的四条系数**（重构 `b23 = Σ_j scale_j·a_j(Θ)·T̃_j23`）：

```
a₁(Θ) = C₁·exp(−C₂yw) + C₃yw + sin(C₄yw)                        # 壁面指数衰减
a₂(Θ) = C₁tanh(C₂yw)·C₃zeta2/(C₆+C₄zeta2) + C₅yw                 # zeta2 饱和 × 壁面
a₃(Θ) = roloc^C₂·yw^C₃ / (C₄yw + C₁log(yw))                      # 旋转幂律 / 壁面对数
a₄(Θ) = C₃tanh(C₄roloc)·(C₁zeta2/(zeta2+C₂) − C₅tanh(C₆eta2))    # 双饱和乘积
```

**g 基 LGF-go v2（0.693）**：

```
a₁(Θ) = C₁/(C₅+C₂yw) + C₃eta2/(C₆+C₄eta2)                        # 壁面有理式 + eta2 饱和
a₂(Θ) = C₁C₂yw·(C₃√roloc + C₄(C₅yw+C₆))                          # 壁面 × 旋转
a₃(Θ) = C₁·exp(−C₂yw)·(C₄+roloc)/(C₃+roloc)                      # 衰减 + roloc 饱和
a₄(Θ) = C₁ + C₃tanh(C₄roloc) − C₅tanh(eta2)                      # 双饱和
```

**e 基 LGF-mg v2（0.983）** 同族：`tanh(roloc)` 饱和、`exp(−yw)` 衰减、`1/(C+eta2)` 有理式——与 SSG/LRR 类 ASM 闭包的标准形态一致。对照 nophys（generic 提示）g 基的 `log(Cyw+C)·log(Cyw+C)`：数值形式无物理对应。PySR 在等复杂度下的解也常出现无物理意义的高频结构。

### 4.5 NMSE 为什么从 10⁻² 涨到 10⁻¹：误差来自常数估计，不来自公式形状

对照两轮量级：标量口径 SOTA 0.0514 / 联合上界 0.0034（10⁻²–10⁻³），本口径 SR 重组解 0.6–1.0（10⁰）。放大机制是**抵消结构 × 逐通道独立估常数**：分解满足 Σ‖C_m‖/‖b23‖ = 99–32 201×（前轮诊断），各通道贡献项必须相互抵消，逐通道独立确定的系数只要差百分之几，重组误差就被放大 2–4 个量级。

**验证（决定性实验）**：固定 SR 找到的公式形状，把 4 通道全部常数拿出来**联合**最小化重组 NMSE（已正式化进 `rc_asm_basisB2.py --stage refit`，Levenberg–Marquardt）。**对 PySR 同样处理**：把其表达式中的内联数值常量替换为符号参数后参与同一联合优化——终口径对两方法完全公平。

全矩阵重拟合结果见 §3.1 最终口径表，三个要点：

1. **公式形状全部被 SR 找对了**——v2 组重拟合后 0.11–0.18（84–92% 误差来自常数估计方式），连 nophys 组（0.157–0.224）都与 physics 组相当，说明两种提示下 SR 找到的形状都可用，差别只在形状的"可联合抛光性"。
2. **m 池爆炸被重拟合治愈**：m_lgf_mg/m_lgf_go 逐通道重组 99.5/117.2 → 联合重拟合 **0.126/0.125**（38 参数），证实前轮"m 池不可救"的结论只对逐通道常数协议成立——病态在系数确定方式，不在池本身；但 PySR 的 m 池解重拟合后仍 0.96–1.17，其形状在抵消结构下不可抛光。
3. **协议失败案例（诚实项）**：g_lgf_go legacy 重拟合发散（0.826→4.52，可复现）、e_lgf_go legacy 无改善（2.154→2.154）——legacy go 的个别形状含奇异结构（inv/除法链），LM 无法收敛；这两组在终口径表中保留原值。

**结论**：论文中该口径的最终数字应报"联合重拟合后"一列；SR 逐通道重组是中间量，用于方法对比（等复杂度、消融）仍然有效——所有方法承受同样的逐通道常数估计协议，对比公平。

### 4.6 大形状轮：系数口径触及 SOTA

v2 组距标量 SOTA 0.0514 还差 2–3×，瓶颈是每通道 4–6 参数的紧凑形状表达力不足（联合上界 0.0034 证明形式本身够用）。大形状轮（maxparams 12、max_edges 24、gens 40）+ 把 48 参联合解的系数结构（β_j(Θ) 显著项）注入物理提示让 G_INIT 高起点：

| 基 | LGF-mg big（SR 中间 / refit 终值） | LGF-go big | 对照 v2 最佳 | PySR full refit |
|---|---|---|---|---|
| g | 0.376 / **0.124** | 0.550 / 0.140 | 0.646 / 0.152 | 0.128 |
| e | 0.792 / **0.0576** | 0.856 / 0.134 | 0.983 / 0.111 | 0.377 |

- **e 基 0.0576 已进入标量 SOTA 0.0514 的 12% 以内**，且 worst-case 仅 0.068（跨 5 工况最稳的解）；g 基 0.124 与 PySR full 重拟合（0.128）持平，复杂度低 3–4 倍。
- 大形状的收益全部来自**形状表达力 × 联合抛光**：SR 中间值改善有限（0.646→0.376），重拟合放大差距（0.152→0.124 / 0.111→0.058）——更大形状给了 LM 更多可调自由度。
- 结构提示（联合解 β_j 显著项注入 G_INIT）与 big 配置联合起效：本轮 4 组 SR 中间值全部好于对应 v2 组。
- 最终口径下的公平对照：**LGF big 形状 + 21–24 参数 < PySR full 形状 + 15–19 参数**（e 基 3.3–6.5×，g 基持平但更简），且 LGF 形状全部落在 ASM 物理族内。

**e 基终口径冠军 e_lgf_mg_big（refit 0.0576）的四条系数**（复杂度 15–22 节点/式）：

```
a₁(Θ) = C₁·log(C₃yw + C₄) + C₂·ret/(C₅ + eta2)                   # 壁面对数 + eta2 饱和
a₂(Θ) = C₁yw/(C₄ + √roloc) + C₂yw + C₃/(C₅ + eta2)               # 壁面/旋转饱和 + 有理式
a₃(Θ) = C₁/(C₅ + C₂roloc) − C₃yw² + C₄·yw/(s2o2 + C₇)            # roloc 有理式 + 壁面衰减
a₄(Θ) = C₁·tanh(C₂roloc + C₃yw) + C₄·roloc/(C₅ + roloc)          # 双变量饱和 + 有理式
```

## 5. 诚实声明（写论文必附）

1. **联合基线 0.0034 是过拟合上界**：48 参数对 635 点，三工况留出检验 test NMSE 达 10²——系数形式的 in-sample 精度不可外推（探针数据 `extrapolation_probe.txt`：任何归一/正则/池组合 test 均 3.6–10⁷）。SR 重组解（0.7–1.0）比联合基线差 2 个量级，但**不会更差于外推失败的上界**——这句话只对 in-sample 口径成立。
2. **m 变体（54 特征池）逐通道重组全部爆炸**（42–117）：混合池的 T 通道与标量块共线更严重；联合重拟合可救 LGF 形状（→0.126）但救不了 PySR 形状（0.96–1.17），m 池结论依协议而定，论文中单列说明。
3. **v 基不可行**：T 通道共线（cond 136–234），联合解 NMSE 1.19，SR 重组 2.9–13.8，重拟合后仍 1.4–2.6。
4. yw 为非局部量（真壁距），严格 Pope 局部口径下系数池只剩不变量，精度 0.30–0.34（前轮已证）。
5. **in-sample 口径警告同样适用于 0.0576**：big 轮 21–24 参数对 635 点，与标量 SOTA 0.0514 的对比仅在 in-sample NMSE 意义下成立；留一外推检验未对 big 组重做（48 参联合解的外推已证不可行，见探针数据）。终口径的价值主张是"严格 g·Tij 结构 + 显式物理族公式 + 精度追平标量 SOTA"，不是外推稳定性。
6. legacy go 两组重拟合失败（g 4.52 发散 / e 无改善）已如实保留原值——联合抛光对含奇异结构的形状不保证收敛。
