# 方案B：纯张量基口径的 b23 闭合 — 结构化联合拟合报告

**日期**：2026-10-16
**动机**：用户指出 `t23full_paper/` 一轮的冠军公式 `b23 = f(roloc, yw)` 不含任何 T⁽ᵐ⁾ 通道，
与 ASM 口径 `b_ij = G(I₁,I₂,…,rot_loc, Re_turb)·T_ij` 不符。本轮把 b23 强制写成该形式重新闭合。
**复现脚本**：`scripts/rc_asm_vw_t23_basisB.py`（`--stage base`）、`scripts/rc_asm_basisB_figs.py`、
诊断链 `scripts/_tmp_t23_basis_diag{,2,3,4,5,6}.py`

---

## 1. 结论（TL;DR）

1. **纯张量基形式可行，且精度与标量 SOTA 同级**：
   `b23 = Σ_{m∈{1,5,6,10}} a_m(Θ)·T̃⁽ᵐ⁾₂₃`，系数 `a_m` 为 Pope 不变量 + rot_loc + Re_t + yw
   的 12 项线性组合（48 个全局常数）。
   **g 基 loss_vw = 0.0530，e 基 0.0482**（worst 0.126 / 0.116）；
   参照：标量 10 基 0.0532、LGF 冠军 0.0514–0.0555。v 基不可行（即使富系数池也 1.32）。
2. **核心机理发现（解释了为什么之前的 LGF 从不用 T 通道）**：
   张量基对 b23 的分解**病态** —— 各通道贡献项必须相互抵消 10²–10⁴ 倍才能得到净 b23
   （Ro7.5 抵消比 557×(g)/99×(e)，Ro150 达 25 534×/32 201×，见 fig1）。
   因此**系数只能联合确定**；任何"逐通道拟合再组装"的路线都会被抵消放大摧毁
   （实测：系数回归自身 loss 1e-8～1e-5，重组后 b23 loss 却爆到 3.8–4.5）。
3. **附带修复**：原 `rc_asm_vw_t23_full.py` 注入 LGF 的物理提示称
   "`T1s = ½dW̄/dy` 关于槽道中心反对称"——**实测错误**，T1/T5/T6/T10 的 23 分量与 b23
   同为**偶对称**（偶残差 0.25%–2%）。已修正并启动 方案A 对照重跑（`runs_vw_t23full_lgf*_ctl/`）。

## 2. 模型形式

```
b23(y) = Σ_{m∈{1,5,6,10}} a_m(Θ) · T̃⁽ᵐ⁾₂₃(y),     T̃⁽ᵐ⁾₂₃ = T⁽ᵐ⁾₂₃ / rms_m
Θ = {1, √roloc, roloc, tanh(roloc), eta2, zeta2, s2o2, ret, log(eta2), yw, yw², yw·√roloc}
```

- `T⁽ᵐ⁾₂₃` 取自 `dataset_trueasm_{g,e}.npz`（k/ε 归一 Pope 基张量的 23 分量）。
- 仅 {T1, T5, T6, T10} 的 23 分量非零（二维平均流的对称性代数必然）。
- Pope 不变量 I3 = s3 = tr(S³) 与 I5 = so2 = tr(SW²) 在该流动中**恒为 0**，故不进池。
- `yw = 1−|y/h|` 为壁面扩展项（非局部量），单独标注；Pope 不变量 + roloc + ret 单独成池
  时 loss 0.30–0.34，加入 yw 后才到 0.048–0.053（见 §5 表）。
- 系数 `a_m` 为全局常数（5 工况通用，无逐工况 K#），满足 ASM 普适性硬规则。

## 4. 为什么"逐通道符号回归"在纯张量基口径下不可行

b23 ≈ 0.02–0.05，而结构化解的各通道贡献项 rms 为 0.05–840（g 基 Ro150：|C5|=|C10|≈329）。
**净输出 = 大数相消**。后果：

| 路线 | 系数自身误差 | 重组后 b23 loss |
|---|---|---|
| 逐点反演（每点 2 自由系数） | 0（精确） | 0，但**不识别**（无约束力） |
| 逐通道 SR（系数 loss 1e-8～1e-5） | 极小 | **3.84 (g) / 4.53 (e)** |
| 联合结构化 lstsq（本轮） | — | **0.0530 / 0.0482** |

结论：**G×T 形式对 b23 的系数辨识本质上是一个联合问题**；"分别学系数再相加"不可用。
这同时解释了原 T23-full 轮的两个现象：LGF 从不选 T 通道（选了就会引入病态项），
PySR 选了也只是把它当过拟合把手。

## 6. 诚实声明（写论文必附）

1. **in-sample 口径**：所有数字为 5 工况联合拟合的 in-sample NMSE，无外推。
   留一工况（LOSO）检验：标量形式 LOSO mean 0.80（Ro150 折 3.5 主导）；
   纯 T / 混合形式在 Ro150 折**全部爆掉**（10²–10³）——张量基形式的 in-sample 增益
   **不能外推到未见旋转数**。若论文声称跨工况预测能力，须用标量形式或降参数。
2. **参数量不对等**：方案B 48 常数 vs LGF 冠军 5–6 参数。0.053 vs 0.055 的"同级"
   是用 ~9× 参数换来的；审稿人可能挑战这一点。
3. **剖面质量**：fig3 显示 G×T 闭合在槽道中心与近壁有可见的振荡（病态性的直接表现），
   NMSE 数字好但剖面不如标量公式光滑。
4. **yw 非局部**：严格 Pope/ASM 口径只允许局部不变量；yw 是壁面扩展。
   只用不变量 + roloc + ret 时精度 0.30–0.34，明确不如含 yw。
5. **v 基不可行**：T 通道共线（条件数 136–234），即使逐工况自由系数 b23 残差仍 ~1.06。
6. **oracle10 ≈ 0** 说明 10 基逐点可精确闭合全张量，但**全局常数**闭合 rel-resid 0.70–0.84
   （`prep_report_trueasm.json`）——差距全部在系数的跨工况普适性上。
