## 1. 实验设置

### 1.1 特征池（相对上轮的唯一增量：+yw）

- 上轮 17 特征：T1..T10（Pope 张量基不变量投影）、s2o2、eta2、zeta2、roloc、ret、k2、S̄
- 本轮新增：**yw = (1−|yh|)·180**（真壁距，y⁺ 单位，替代 09-30 失败的 ypd 带符号伪距离）
- 数据坐标：yh ∈ [−1,1]（yh=±1 为中心，0 为壁）→ yw=0 在壁面、180 在中心

### 1.2 12 组配置

| 引擎 | 后端 | 说明 |
|---|---|---|
| pysr × {v,g,e,m} | PySR（内部Regressor） | 40 min timeout 实际 22–46 s；复杂度上限 30 |
| lgf_go × {v,g,e,m} | **MiniMax-M2.7 真实 LLM**，ginit_only（G_INIT 单次生成 30 候选 + paramfit + GP 精修） | budget 600 s；实际 375–1797 s |
| lgf_mg × {v,g,e,m} | 同上，且 M_GUIDE 通道开启（`ginit_only=False`：进化中每 10 代调 LLM 提变异建议） | 实际 954–2834 s |

口径：所有跑批为**系数/分量拟合**（scalar_fit），非真 ASM 方程求解。NMSE 分母 = var_c（各工况真值方差），与 `rc_asm_vw_only.py:127` 正式口径一致。

## 3. 逐工况分析（图 fig2/fig4）

### 3.1 前二名逐工况 NMSE

| Ro_τ | pysr/m | lgf_go/e | 上轮最优 lgf_mg/g(无yw) |
|---|---|---|---|
| 7.5 | 0.058 | 0.010 | 0.045 |

| 75 | 0.021 | 0.132 | 0.058 |
| 150 | 0.034 | 0.187 | 0.301 |

- **pysr/m 全工况 ≤0.058 且无短板**（Ro30 达 0.0024，接近该工况的拟合极限）；
- lgf_go/e 在低 Ro 甚至优于 pysr/m（Ro7.5: 0.010），但**随 Ro 单调恶化**（Ro150: 0.187）——其 √roloc 主导结构在高 Ro 幅值衰减不足；

### 3.2 ρ–Ro 行为

前 5 名的逐工况 ρ 均稳定在 0.95–0.999，无上轮 PySR 的"高 Ro 单调衰减（0.70→0.42）"现象；所有组的 ρ 在 Ro150 处最低但 ≥0.92。形状层面 12 组全部合格，差距全在**幅值与偏置**——再次印证 NMSE 为主判据的必要性。

## 4. 公式解读（图 fig3 剖面对比）

### 🥇 pysr/m（NMSE 0.033）

```
b23 ≈ 0.0581 / ( 0.557 + (T4_g + roloc)·[ 0.187·roloc·log(roloc)/yw
                                    + 4.59·(roloc/yw + 1.86)/roloc ] / roloc )
```

- 核心结构 = **roloc/yw 嵌套比值**：旋转局部数与真壁距的竞争组合，分子分母双饱和；
- 同时保留旋转通道（roloc, T4_g）与壁面通道（yw），无单通道丢弃；
- complexity 28 全场最复杂，但 5 工况一致好——非过拟合形态（无逐工况重参数化）。

### 🥈 lgf_go/e（NMSE 0.085）

```
b23 ≈ −√roloc · ( C3·log(yw) + C2·roloc ) + C1·zeta2
```

- **可分离乘积形**：f(roloc)·g(yw)，外加 zeta2 修正；仅 3 参数；
- LLM 一次性生成中结构最接近 pysr/m 者，但缺 roloc·log(roloc)/yw 的嵌套深度 → 高 Ro 幅值欠拟合（§3.1）。

### 其余组的两类失败模式

| 失败模式 | 组 | 公式 | 后果 |
|---|---|---|---|
| **只用 yw 丢旋转通道** | lgf_mg/v | `C1·log(1+C2·yw)` | 高 Ro NMSE 0.35–0.55（b23 幅值对 Ro 强敏感，丢通道必塌） |
| | lgf_mg/g | `C4·C5·yw/(yw+C2·C3·yw/(yw+C1))`（yw 连分式） | 同上 |
| **物理形态对但幅值欠** | lgf_mg/m | `C2·yw^C3·exp(−C1/roloc)`（幂律×旋转衰减） | 形态有趣（ρ 0.988），中低 Ro 好，Ro30/150 欠 0.50 |
| | pysr/e | `0.0168·√(0.0287·yw+1.74)·exp(−(eta2+1.38)/zeta2)` | ρ 全场最高但幅值/偏置欠 → NMSE 0.286 |

**通用结论：凡是把 roloc 与 yw 两个通道都保留的公式（pysr/m、lgf_go/e）进入前二；丢任一通道的公式稳定在后 1/3。**

## 5. ⚠️ 专节：LGF DSL 往返参数错位 bug

### 5.1 现象

lgf_go/m 管线记录 loss_vw = **4043**（"爆炸"），但该候选在 paramfit 内部的 loss = **0.360**（result.json `loss_paramfit` 字段）。两者天差地别。

### 5.2 根因链（三层证据，全部可复现）

1. **最小复现**：
   `parse_dsl('(C3*(1))*(sqrt(C2*(yw)))+C1*(zeta2_e)').to_sympy()` → `C1*zeta2_e + C2*sqrt(C3*yw)` —— **C2/C3 换位**。
2. **重命名机制**：`Graph.__init__ → _normalize_params()`（`lgf/graph.py:227`）按**树遍历序**把参数重命名为 C1..Cn、丢弃原名；`to_dsl` 打印的是训练图中的名字。
3. **树形改变**：解析端 `_build_mul`（`lgf/dsl.py:335-372`）对 bare-param 子节点（`(C3*(1))` 形状）做合并重构——系数被抽出挂到首个真实子项边上 → 树遍历序变 → 重编号不同 → **DSL 打印–解析往返不是恒等映射** → paramfit 优化好的 θ 套在了参数错位的公式上。

lgf_go/m 的 best 公式恰为触发形状 `(C3*(1))*(sqrt(C2*(yw)))+C1*(zeta2_e)`，θ 错位后评估爆炸至 4043。

### 5.3 波及面（重要：经正式口径重验，波及面窄）

用独立文本求值器（DSL 串本身是合法 Python 表达式；θ 按排序后参数名对位——该约定经 8 组逐一验证成立）对全部记录重评：

| 验证对象 | 结果 |
|---|---|
| yw 轮 11 组（除 lgf_go/m） | **10/11 记录值与文本语义求值精确一致（偏差 <5%）** ✅ |
| yw 轮 lgf_go/m | **唯一真中招**：记录 4043 vs 文本 0.360（loss_paramfit 实锤 paramfit→fresh-parse 之间换参） |
| 上轮（无 yw）7 组 LGF | 6/7 精确一致；lgf_mg/g（上轮 SOTA 0.110）DSL 引用 C5 而 θ 仅 4 个，文本求值器不适用，但**管线自洽验证通过**：loss_paramfit(0.11025297) 与重编译评估(0.11025298) 8 位有效数字一致 → 0.110 记录可信 |

**触发条件**：公式树含 `(C#*(1))` bare-param 构造（GP 变异或 LLM 生成特定写法时出现）。PySR 不受影响（自有 predict 路径，无 DSL 往返）。

**修复待办**（未实施）：parse 保名（保留原参数名）或 to_dsl 规范化打印形状；修复前任何含 bare-param 形状的 LGF 结果须以 `loss_paramfit` 交叉核对。

## 6. ⚠️ 方法学教训：一次错误的"全面翻案"与撤回

**诚实记录，写进报告是为了论文评估章节不再踩同一个坑。**

1. 发现 lgf_go/m 记录爆炸后，我用独立文本求值器复查全部 LGF 组，得"8/8 全部 MISMATCH，真实 SOTA 是 lgf_go/e = 0.0121"的结论并已向用户汇报。
2. **该结论是错的**：复查脚本的 NMSE 分母用了 `mean(y²)`，而正式口径是 `var_c = var(yfit)`（`rc_asm_vw_only.py:127`）。b23 偏置主导（mean/std 1.55–2.91），两分母相差 4–9 倍 → 大规模假阳性。
3. 用正式分母重验后：10/11 精确一致，唯一真 MISMATCH 仅 lgf_go/m（§5）。"lgf_go/e = 0.0121 真 SOTA"**撤回**，正确值为 0.085（第二名）。

**教训（三条，进论文评估章节）**：
- **复查评估必须先对齐正式分母口径**，任何第二实现先在无争议样本上对拍；
- **ρ 与 NMSE 信息互补**：偏置主导信号必须看 NMSE(var_c)，ρ 会漏掉系统性偏置与幅值误差（pysr/e 案例）；
- 排除评估 bug 时，"记录值 vs 独立重算不一致"有真假两类：管线 bug（lgf_go/m）与复查器自身口径错误（本节），**必须双向排查**。

## 7. LGF 本轮落后的归因（与上轮"换后端"的对比）

| # | 因子 | 证据 |
|---|---|---|
| 1 | **上轮 LGF 的功臣是 GP 爬山，不是"LLM"** | 上轮 heuristic 假 LLM 只给 3 个平凡种子（`lgf/llm_ops.py:295`：T1+T2 / T1·T2 / T1²+T2²）；0.110 饱和公式是 GP 40 代从平凡种子组装的。本轮 minimax 30 个复杂候选，**best 全部 = G_INIT 原始候选**（top0–4 同 loss 同 DSL，GP 零改进）→ LGF 退化为"一次性生成 + paramfit" |
| 2 | **paramfit 挤占 GP 预算** | 30 候选 vs 3 候选，初始 paramfit 开销 ~10×；lgf_mg/m elapsed 2834 s ≫ budget 600 s；GP 尚未爬山时间已被候选评估吃掉 |
| 3 | **one-shot 抓不到嵌套比值结构** | pysr/m 的 roloc·log(roloc)/yw 三基元组合靠 GP 增量变异拼出；LLM 候选最深只到可分离乘积形（lgf_go/e）。另有 yw∈[0,180] 尺度病（θ 压至 2.7e-7）与解析率不稳（m 变体 6/30、g 变体 3/30） |

**改进路线（公平对比协议，已与用户确认）**：
- ~~双阶段 hybrid（PySR 种子喂 LGF）~~ —— **用户裁定为作弊，撤回**：LGF 拿了 SR 的搜索成果，无法比较；仅可作工程流水线，不进论文对比表。
- **合法修复**（不构成信息泄漏）：① paramfit 限时/降候选数，把 GP 时间还回来；② 特征标准化（yw/180）+ paramfit 多 start；③ 修解析率；④ 修 DSL 往返 bug；⑤ G_INIT prompt 加**通用多样性规则**（候选不得只用 yw 丢 roloc——此条来自 LGF 自身失败诊断，非 PySR 公式）。**禁止**把 roloc/yw 比值形写入 prompt（信息泄漏）。
- 复合特征池实验必须**双方同池**（PySR 与 LGF 都拿同一套新特征重跑）才可比较。
- 预期管理：修完后 LGF 仍可能输——那也是有价值的负结果（LGF 定位 = 精修器/先验注入器，而非发现器）。

## 8. 结论与局限

### 结论

1. **yw 特征必要且高效**：SOTA 从 0.110 → 0.0329（3.3×），高 Ro 工况改善最大（Ro150: 9×）；前二名公式均保留 roloc+yw 双通道 → 局部不变量不足以参数化 Re_τ=180 壁面效应。
2. **本轮 PySR 胜出**（NMSE 与 ρ 双口径均在榜首区），且用时低 1–2 个数量级；LGF 的 minimax 真实 LLM 后端有效（lgf_go/e 0.085 > 上轮全部 heuristic 结果），但在当前搜索预算/解析率/尺度配置下不敌 PySR 的增量变异搜索。
3. DSL 往返 bug 真实存在但波及面窄（1/8 组）；上轮结论（lgf_mg/g 0.110）经管线自洽验证**维持有效**。
4. 评估方法学：b23（偏置主导）以 NMSE(var_c) 为主、ρ 为辅；双实现复查必须先对齐分母口径。

### 局限（诚实声明）

- 单 seed、单次跑批：排名中相差 <2× 的组（如 #5–#8）顺序不可靠，结论级对比需 cross-seed；
- LGF 的 M_GUIDE 通道本轮**真实执行**（lgf_mg/e: 4 次调用、20 个变异应用、**alive=0**——无一存活进入下一代），与 10-08 v3 消融"M_GUIDE 对 minimax 后端结构性损害、alive 全 0"一致；因此 lgf_mg 与 lgf_go 的成绩差异主要来自随机性（不同 seed）与 M_GUIDE 调用挤占预算（lgf_mg/e 1046 s vs lgf_go/e 375 s），而非 M_GUIDE 本身的增益；
- paramfit 单 start 无 hard deadline（lgf_mg/m 2834 s 超时问题已知未修）；
- 所有结果为 scalar_fit 口径（系数拟合），非真 ASM 方程求解的泛化性能。
