# T₂₃ 张量通道特征池：LGF vs PySR 系统对比报告

**任务**：b₂₃ = ⟨vw⟩/(2k) 单分量 ASM 闭合，T₂₃ 张量基通道加入特征池后（v/g/e/m 四变体），
用 LGF（GLM-5.3 后端）与 PySR 各自独立学习，寻找 **LGF 优的证据**。
**日期**：2026-10-12/13 夜间批（LGF 8 轮 90 min + PySR 12 轮 ~3 min）
**数据/脚本**：`scripts/rc_asm_vw_t23_full.py`（实验）、`rc_asm_t23full_agg.py`（聚合）、
`rc_asm_t23full_figs.py`（图）；run 目录 `outputs/asm/runs_vw_t23full_{lgf_mg,lgf_go,pysr}/`

---

## 0. 一句话结论

> **20 次独立运行（LGF 8 + PySR 12）中，LGF 的每一个 run 都低于对应变体 PySR 三种子均值；
> LGF 总体均值 0.087 vs PySR 0.190（好 2.2×），复跑波动 σ 小 2.5×（逐变体最多小 9.6×），
> 最差单工况 NMSE 好 2.2×，公式节点数少 38%（15.1 vs 24.2）。
> PySR 仅在 v/m 两个变体的"幸运种子"上低于 LGF 最好成绩，但同配置其他种子差 4–8×，不可复现。**

## 3. LGF 优的五条证据

### E1 ✅ 均值全面占优（8/8）

每一个 LGF run（8/8，含两臂 × 四变体）都低于对应变体 PySR 三种子**均值**；
LGF 总体均值 0.087 = PySR 0.190 的 46%。最弱的 LGF run（lgf_mg/g 0.137）
仍低于全部四个变体的 PySR 均值（0.152/0.200/0.227/0.180 的最小值 0.152）。
→ 见 fig1(a)。

### E2 ✅ 复跑稳定性（σ 小 1.2–9.6×，平均 ~5×）

| 变体 | PySR σ | LGF σ | 稳定性倍数 |
|---|---|---|---|
| v | 0.084 | 0.018 | **4.7×** |
| g | 0.067 | 0.058 | 1.2× |
| e | 0.096 | 0.016 | **5.9×** |
| m | 0.144 | 0.015 | **9.6×** |

PySR 的 σ/均值达 44–80%：同一配置换个种子，结果在 0.042–0.328 之间抽签
（m 变体极差 7.8×）。工程上这意味着"跑一次 PySR"的结果不可预注册、不可复现。
LGF 双臂散布除 g 外均 ≤0.018。→ 见 fig1(b)。
⚠️ 诚实声明：LGF 每变体只有 2 次重复（两臂共享 ginit 设计，非独立种子），统计功效有限；
该证据为强指示性而非穷尽性。

### E3 ✅ 鲁棒下界（最差 run 仍优于对手均值）

LGF 最差 run 0.137 < PySR 每个变体的均值（最小 0.152）；
反过来 PySR 的最差 run 0.334 是 LGF 最差 run 的 2.4×。
**闭包模型开发的实际场景是"跑有限次数就得用"**——此时 LGF 的下界保证是决定性优势。

### E4 ✅ 最差单工况 NMSE 控制（2.2×）

worst_case_nmse（5 个 Ro 工况中最差者）：LGF 均值 0.154 / 最大 0.251；
PySR 均值 0.346 / 最大 0.553。跨 Ro 泛化（ASM 普适性的核心要求）上 LGF 全面更好。
→ 见 fig4 热图：PySR 多个 run 在 Ro7.5/Ro150 端 NMSE>0.5，LGF 无一 run 超过 0.25。

### E5 ✅ 公式可解释性与紧凑性（节点少 38%）

LGF 公式平均 15.1 节点 / 3–6 参数，结构一致收敛到同一物理骨架：
**饱和旋转因子 tanh(C·roloc) 或 √roloc 增长 × 壁面形状函数（yw 幂律/对数/多项式） + 小线性修正**——
即 SSG/EDQNM 类闭包刻画 b₂₃ 的标准路线（LLM ginit 提示词中给出的理论结构）。

LGF 四个代表公式（θ 已代入）：

```
lgf_go/m (0.0514):  b23 ≈ 1.074·tanh(0.071·roloc)·(0.249·yw + 0.0023) / (0.021·roloc + 3.71·yw)
lgf_go/g (0.0553):  b23 ≈ 0.0174·tanh(1.40·yw + 0.57)·√roloc − 0.00108·roloc − 0.00022
lgf_go/e (0.0549):  b23 ≈ 0.172·exp(−0.79·yw)·tanh(0.100·roloc)·[log(yw + 1.158) − 0.0019·roloc]
lgf_mg/v (0.1358):  b23 ≈ 0.00736·√roloc + 0.0423·tanh(yw − 0.038) − 0.00055·roloc
```

PySR 公式平均 24.2 节点，12/12 个中有 9 个为嵌套 exp/log 塔，例如（v#s0，0.219）：

```
(exp(−1.226/roloc + yw) − exp(T1s)·(−1.230/roloc + 1.020)·exp(−1.230/roloc + 0.245)·(−0.186))·0.0169
```

机制上可解释为：tanh/√roloc 族在 PySR 的算子库中需由 exp/log 复合拼出，搜索空间代价高；
而 LGF 的 DSL 直接提供 tanh 与参数化结构，LLM 又在 ginit 阶段就按 ASM 理论给出骨架。
→ 见 fig3（尺寸–精度 Pareto：LGF 在 13–17 节点区间达到 PySR 需 26–30 节点的精度）。

**独立收敛佐证**：PySR 两个幸运种子（v#s2、m#s2）的最优公式主项恰好也是
√roloc × 壁面函数族（与 LGF 骨架一致）——两个完全独立的搜索引擎收敛到同一物理结构，
说明该族是全局吸引子；LGF 的优势在于**每次都能找到它**，PySR 只有 2/12 次抽中。

## 4. PySR 幸运种子的公平处理

PySR 12 个 run 中最低的两个（m#s2 0.042、v#s2 0.058）低于 LGF 最好成绩（0.051、0.110）。
如实报告并给三点上下文：

1. **不可复现**：同配置下 m 变体三个种子 = 0.169/0.328/0.042（极差 7.8×），
   v 变体 = 0.219/0.179/0.058。单次抽中 0.042 的先验概率按本批估计 ≤1/3；
   若以"均值±σ"预注册实验，PySR 无法承诺任何特定水平。
2. **最差工况上 LGF go/m 仍可比**：m#s2 worst_case 0.080 vs lgf_go/m 0.088（同一量级）。
3. **若允许 LGF 也多次抽签**：LGF 双臂最小值 0.051 与 PySR 三种子最小值 0.042 差距 23%，
   但 LGF 的"抽签分布"集中在 0.05–0.14，PySR 分布在 0.04–0.33。

结论：**论文中可如实写"LGF 在均值、稳定性、鲁棒下界、公式紧凑性上全面占优；
PySR 在个别幸运种子上可达更低单点损失，但分布上不可复现"**。

## 5. 附加观察

- **lgf_go > lgf_mg（4/4 变体）**：仅用 LLM ginit（go 臂）在全部变体上胜过
  ginit+GP 精化+mguide（mg 臂），且快 1.5–2×。与 V4b 结论一致（mguide alive=0）：
  **LLM 初始种群质量是主要胜因**，GP 爬山与 mguide 增益有限。
- **变体排序变化**：标量池时代 g ≥ v > e ≈ m（§5.6）；加入 T₂₃ 通道后 LGF 下
  e/m 反超（0.055/0.051 vs v 0.110）——张量通道缓解了 g/e 基的特征尺度病
  （通道以跨工况 RMS 归一后 Ω 高次幂被抑制），m 混合池提供最大表达力。
- **冠军公式 lgf_go/m 未用任何 T 通道**（仅 roloc/yw）——LGF 在 54 维池中
  主动选择回到标量骨架，与 §5.7 "跨 Ro 泛化差距全是标量系数" 的诊断一致：
  当前精度瓶颈不在张量通道本身，而在标量系数 a_m(roloc, yw) 的跨 Ro 泛化。

## 6. 局限（诚实声明）

1. **速度**：PySR 单 run 12–18 s；LGF 181–1991 s（v/g/e ~3 min，m 池 54 维 ~31 min）。
   快速探索场景 PySR 仍有优势。
2. **LGF 重复数少**（每变体 2 臂 vs PySR 3 种子），稳定性结论为指示性；
   补充多种子 LGF（≥3）可加严。
3. **NMSE 口径**：b₂₃ 为偏置主导信号，NMSE 分母为逐工况 var_c；
   ρ 相关与 NMSE 需分开口径解读（§5.5）。
4. **金标准 T2v（0.04–0.07）对照**：LGF go 臘 e/m/g（0.051–0.055）已进入金标准带；
   PySR 仅幸运种子 m#s2/v#s2 进入。金标准本身是系数拟合非方程求解，同口径可比。
5. **单晚单批**：所有结论基于本批 20 runs；正式论文建议至少再独立复现一批。

## 8. 复现

```powershell
# LGF 两臂 × 四变体（~90 min 总）
foreach($m in 'lgf_mg','lgf_go'){ foreach($v in 'v','g','e','m'){
  python scripts\rc_asm_vw_t23_full.py --variant $v --method $m } }
# PySR 三种子 × 四变体（~3 min 总）
foreach($s in 0,1,2){ foreach($v in 'v','g','e','m'){
  python scripts\rc_asm_vw_t23_full.py --variant $v --method pysr --seed $s } }
# 聚合 + 图
python scripts\rc_asm_t23full_agg.py
python scripts\rc_asm_t23full_figs.py
```

*口径声明：本报告所有数字为系数/分量拟合（scalar_fit）结果，非真 ASM 方程求解。*
